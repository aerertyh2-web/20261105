# Zeabur 环境变量清单

本文件说明云端运行所需的 5 个环境变量。密钥值只保存在本机受保护文件 `data/zeabur-variables.txt` 中，不在本文档、Git 仓库或聊天里出现。

## 一、5 个变量

| 变量名 | 取值 | 说明 |
|---|---|---|
| `SECRET_KEY` | 已生成的随机长字符串 | Flask 会话签名密钥；更换后所有登录状态失效 |
| `DATA_ENCRYPTION_KEY` | 已生成的 Fernet 32 字节密钥 | 加密企微 Webhook 等敏感字段；更换后旧密文无法解密 |
| `TZ` | `Asia/Shanghai` | 容器时区，保证北京时间 |
| `DATA_DIR` | `/data` | 数据库、上传、备份、日志统一放在持久卷 |
| `PORT` | `8080` | 容器内监听端口 |

云端与本地是两套独立密钥：本地 `.env` 的 `DATA_DIR=./data`、`PORT=5000` 保持不变，互不影响。

## 二、打开密钥清单（图形界面）

1. 在文件资源管理器的地址栏输入 `D:\qoder\data` 并回车。
2. 找到 `zeabur-variables.txt`，右键 → **打开方式** → **记事本**。
3. 文件共 5 行，格式为 `变量名=值`，可整份全选复制。
4. 粘贴完成后关闭记事本，不要另存为、不要发到聊天或截图。

该文件已排除在 Git 之外，也已被 Windows 权限收紧为仅当前用户可读。**不要**把它放进上传 GitHub 的压缩包。

## 三、填入 Zeabur（图形界面）

1. 浏览器打开 Zeabur 控制台并登录，进入本项目。
2. 在项目里点开要部署的服务，进入 **Variables**（环境变量）页。
3. 逐个新增 5 个变量：点 **Add Variable** / **+**，`Key` 填变量名，`Value` 填对应的值；若页面提供批量编辑或 `.env` 导入入口，可直接粘贴清单中的 5 行。
4. 保存后 Zeabur 会自动重新部署；在 **Deployments** / **Logs** 页等待新版本启动完成。

界面按钮名称可能随 Zeabur 版本略有差异，位置固定在服务的 Variables 页。

## 四、必须同时确认的两件事

- **持久卷**：在服务的存储/Volumes 设置中，把持久卷挂载到 `/data`。否则容器重建后数据库和上传文件会丢失。
- **单实例**：本项目使用 SQLite，服务实例数必须保持 1，不能开启多副本。

## 五、安全提醒

- 变量值一旦填入 Zeabur，就以平台保存的为准；本机这份清单只作为备份，可继续保留。
- 如果怀疑泄露：在 Zeabur 的 Variables 页修改 `SECRET_KEY` 会让所有用户重新登录；修改 `DATA_ENCRYPTION_KEY` 会导致已加密的企微配置无法解密，需要重新填写企微 Webhook。
- 不要把 `data/` 目录打进上传 GitHub 的压缩包，也不要截图 Variables 页面。

## 六、开发方校验方式

```bash
.venv\Scripts\python scripts\prepare_zeabur_env.py --check
```

只检查变量名、固定取值和密钥格式，不显示密钥内容。清单已存在时，生成脚本不会覆盖，避免误换密钥。
